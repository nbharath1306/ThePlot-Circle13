## ⚠️ Important Ethical Notes

**PLEASE READ BEFORE BUILDING:**

This project involves AI generating relationship predictions. While technically impressive, it raises ethical concerns:

1. **Safety First:** All safety features (disclaimers, positive bias, mental health resources) are MANDATORY
2. **No Data Storage:** User data must be ephemeral (30-minute expiry)
3. **Positive Outcomes:** Enforce 70% positive outcomes in AI prompts
4. **No Trauma:** Never simulate abuse, severe harm, or traumatic events
5. **Monitor Impact:** Watch for user distress and be ready to intervene

See `01_PRD_ThePlot.md` Section 10 (Risk Management) for full details.

**Alternative:** If uncomfortable with the original concept, see `fate_exe_research.md` Section 6 for the "Relationship Stress Test" ethical redesign.
